Technical Viva Note: Empirical vs. Asymptotic Analysis
Why do timings fluctuate between executions?

In modern Java Virtual Machines, execution speed is influenced by: Just-In-Time (JIT) Tiered Compilation (C1/C2 compilers), Garbage Collection (GC) pauses, and CPU Hardware Cache (L1/L2/L3) line hits. StockMaster applies a pre-benchmark warm-up loop and computes arithmetic averages across 40 trials to yield statistically rigorous measurements.

Why is Quick Sort often empirically faster than Merge Sort?

While both boast O(N log N) average time complexity, Quick Sort sorts in-place with excellent spatial CPU cache locality and minimal auxiliary allocations (O(log N) stack). Merge Sort requires allocating an auxiliary buffer array of size O(N), introducing slight heap copying overhead.
